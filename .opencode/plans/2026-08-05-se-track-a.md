## Phase 4: Track B — Forward-Authoring Path

### Task 16: Design the author workflow

**Concept:** `architecture-model author <requirements-doc>` parses a requirements document (markdown with bullet lists, numbered requirements, or structured format) and scaffolds a model with:
- Actors (from stakeholder mentions)
- Capabilities (from functional requirements)
- Constraints (from non-functional requirements)
- Initial `derives-from` relationships (from nesting/grouping)

The user provides intent BEFORE code exists. The output is a `.architecture-model.yaml` with entities in `concept` lifecycle phase.

**MCP tool:** `architect_author(repo_path, requirements_text) -> dict` — same workflow, callable by agent.

### Task 20: Implement live development gate

**Files:**
- Create: `architecture-model-standard/src/architecture_model/authoring/gate.py`
- Test: `tests/test_development_gate.py`

**Concept:** A "development gate" function that takes a model + manifest and reports whether the code is tracking toward the authored architecture:

```python
def check_development_gate(model: ArchitectureModel, manifest: Manifest) -> GateResult:
    """Check if code reality is tracking toward authored architecture intent.
    
    Returns:
        GateResult with:
        - capability_realization: % of authored capabilities realized by components
        - constraint_allocation: % of constraints allocated to components
        - file_coverage: % of source files mapped to components
        - overall: weighted average
        - phase: current lifecycle phase
        - phase_requirements_met: bool (concept = lenient, production = strict)
    """
```

**Lifecycle gating (2-phase):**
- `concept`: Only requires capability/constraint entities exist. Doesn't check file_coverage, signatures, test_contracts.
- `production`: Full validation — file_coverage > 80%, all leaf constraints verified, all components have signatures.

**Step 1: Write tests**

```python
def test_concept_phase_is_lenient():
    """In concept phase, missing file coverage is OK."""
    model = _make_model(phase="concept", capabilities=3, components=0)
    manifest = _make_manifest(modules=10)
    result = check_development_gate(model, manifest)
    assert result.phase_requirements_met is True  # concept = lenient

def test_production_phase_is_strict():
    """In production phase, need full coverage."""
    model = _make_model(phase="production", capabilities=3, components=1)
    manifest = _make_manifest(modules=10)
    result = check_development_gate(model, manifest)
    assert result.phase_requirements_met is False  # only 1 component for 10 modules
```
